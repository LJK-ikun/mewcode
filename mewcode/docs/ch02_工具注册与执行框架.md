# CH02: 工具注册与执行框架

## 从一次工具调用说起

你问 AI："帮我读取 README.md 的内容"

AI 回复："好的，让我读取这个文件"，然后屏幕上出现：

```
[调用工具: ReadFile]
参数: {"file_path": "README.md"}
执行中...
[结果]
1    # MewCode
2    A powerful code assistant...
```

这个过程背后发生了什么？

1. AI 决定调用 `ReadFile` 工具
2. 系统找到 `ReadFile` 的实现代码
3. 验证参数是否合法
4. 执行文件读取
5. 返回结果给 AI

这就是**工具注册与执行框架**要解决的问题。

---

## 第一步：工具是如何定义的

### 工具的本质：结构化的函数

想象你要教 AI 使用一个函数，你需要告诉它：

1. **函数名**是什么
2. **功能**是什么
3. **参数**有哪些，每个参数什么类型
4. **如何执行**这个函数

系统把这些信息结构化成了 `Tool` 抽象类：

```python
class Tool(ABC):
    name: str                        # 工具名称
    description: str                 # 功能描述
    params_model: type[BaseModel]    # 参数模型（Pydantic）
    category: ToolCategory           # 类别："read" / "write" / "command"
  
    @abstractmethod
    async def execute(self, params: BaseModel) -> ToolResult:
        """执行工具，返回结果"""
        ...
  
    def get_schema(self) -> dict[str, Any]:
        """生成工具的 JSON Schema，发给 AI"""
        ...
```

### 实战案例：ReadFile 工具

让我们看一个真实的工具是如何定义的：

```python
# 第 1 步：定义参数模型
class Params(BaseModel):
    file_path: str = Field(description="要读取的文件路径")
    offset: int = Field(default=0, description="从第几行开始读")
    limit: int = Field(default=2000, description="最多读多少行")

# 第 2 步：实现工具类
class ReadFile(Tool):
    name = "ReadFile"
    description = "读取文件并返回带行号的内容"
    params_model = Params
    category = "read"
    is_concurrency_safe = True  # 可以并发执行
  
    def __init__(self, file_cache=None, file_state_cache=None):
        self._cache = file_cache
        self._state_cache = file_state_cache
  
    async def execute(self, params: Params) -> ToolResult:
        path = Path(params.file_path)
    
        # 错误处理
        if not path.exists():
            return ToolResult(
                output=f"Error: file not found: {params.file_path}",
                is_error=True
            )
    
        # 读取文件（带缓存）
        text = self._cache.get(str(path)) if self._cache else None
        if text is None:
            text = path.read_text(encoding="utf-8")
            if self._cache:
                self._cache.put(str(path), text)
    
        # 切片并加行号
        lines = text.splitlines()
        selected = lines[params.offset : params.offset + params.limit]
        numbered = [
            f"{i + params.offset + 1}\t{line}" 
            for i, line in enumerate(selected)
        ]
    
        return ToolResult(output="\n".join(numbered))
```

### 为什么用 Pydantic？

**问题**：AI 返回的参数是 JSON 字符串：

```json
{
  "file_path": "README.md",
  "offset": 0,
  "limit": 2000
}
```

**需求**：

1. 验证类型（`offset` 必须是整数）
2. 验证范围（`limit` 不能是负数）
3. 提供默认值
4. 自动生成 JSON Schema 给 AI

**Pydantic 一行搞定**：

```python
params = Params.model_validate(arguments)
# 自动验证类型、范围、必填项
# 验证失败抛出 ValidationError
```

## 第二步：工具注册表 - 系统的工具箱

### 问题：AI 说要用 ReadFile，系统怎么找到实现代码？

答案：**工具注册表（ToolRegistry）**

```python
class ToolRegistry:
    def __init__(self):
        self._tools: dict[str, Tool] = {}      # 工具名 -> 工具实例
        self._disabled: set[str] = set()       # 禁用的工具
        self._discovered: set[str] = set()     # 延迟加载的工具
  
    def register(self, tool: Tool):
        """注册一个工具"""
        self._tools[tool.name] = tool
  
    def get(self, name: str) -> Tool | None:
        """根据名称获取工具"""
        return self._tools.get(name)
  
    def is_enabled(self, name: str) -> bool:
        """检查工具是否启用"""
        return name in self._tools and name not in self._disabled
```

### 工具的生命周期

```
定义工具类 (ReadFile)
    ↓
创建工具实例 (ReadFile(file_cache=...))
    ↓
注册到 ToolRegistry (registry.register(tool))
    ↓
生成 JSON Schema (tool.get_schema())
    ↓
发送给 AI (作为 tools 参数)
    ↓
AI 决定调用 (返回 ToolCallComplete 事件)
    ↓
从注册表查找 (registry.get("ReadFile"))
    ↓
验证参数 (params_model.model_validate(...))
    ↓
执行工具 (tool.execute(params))
    ↓
返回结果 (ToolResult)
```

### 工厂函数：批量注册工具

```python
def create_default_registry(file_cache=None, file_history=None) -> ToolRegistry:
    """创建默认的工具注册表"""
    file_state_cache = FileStateCache()
  
    registry = ToolRegistry()
  
    # 注册文件操作工具
    registry.register(ReadFile(
        file_cache=file_cache, 
        file_state_cache=file_state_cache
    ))
    registry.register(WriteFile(
        file_cache=file_cache, 
        file_history=file_history,
        file_state_cache=file_state_cache
    ))
    registry.register(EditFile(
        file_cache=file_cache,
        file_history=file_history,
        file_state_cache=file_state_cache
    ))
  
    # 注册其他工具
    registry.register(Bash())
    registry.register(Glob())
    registry.register(Grep())
  
    return registry
```

**依赖注入的优势**：

- `file_cache` 可以换成 Redis 缓存
- `file_history` 可以记录文件变更历史
- 测试时可以注入 Mock 对象

## 第三步：工具执行 - 从 AI 指令到实际操作

### 数据流：AI 的工具调用如何变成代码执行

```
AI 流式响应
    ↓
ToolCallStart 事件
    tool_name: "ReadFile"
    tool_id: "call_123"
    ↓
ToolCallDelta 事件 (多次)
    累积 JSON 片段: '{"file' + '_path":' + '"README.md"}'
    ↓
ToolCallComplete 事件
    tool_name: "ReadFile"
    tool_id: "call_123"
    arguments: {"file_path": "README.md", "offset": 0, "limit": 2000}
    ↓
[系统接手，开始执行]
```

### 执行流程的关键步骤

在 `agent.py` 中，`_execute_single_tool_direct()` 方法负责执行：

```python
async def _execute_single_tool_direct(
    self, tc: ToolCallComplete
) -> _ToolExecResult:
    start = time.monotonic()
  
    # 步骤 1：从注册表查找工具
    tool = self.registry.get(tc.tool_name)
    if tool is None:
        return _ToolExecResult(
            tool_id=tc.tool_id,
            tool_name=tc.tool_name,
            result=ToolResult(
                output=f"Error: unknown tool '{tc.tool_name}'",
                is_error=True
            ),
            elapsed=time.monotonic() - start,
            is_unknown=True,
        )
  
    # 步骤 2：检查工具是否被禁用
    if not self.registry.is_enabled(tc.tool_name):
        return _ToolExecResult(
            tool_id=tc.tool_id,
            tool_name=tc.tool_name,
            result=ToolResult(
                output=f"Error: tool '{tc.tool_name}' is disabled",
                is_error=True
            ),
            elapsed=time.monotonic() - start,
            is_unknown=False,
        )
  
    # 步骤 3：验证参数
    try:
        params = tool.params_model.model_validate(tc.arguments)
    except ValidationError as e:
        return _ToolExecResult(
            tool_id=tc.tool_id,
            tool_name=tc.tool_name,
            result=ToolResult(
                output=f"Parameter validation error: {e}",
                is_error=True
            ),
            elapsed=time.monotonic() - start,
            is_unknown=False,
        )
  
    # 步骤 4：执行工具
    try:
        result = await tool.execute(params)
    except Exception as e:
        result = ToolResult(
            output=f"Tool execution error: {e}",
            is_error=True
        )
  
    # 步骤 5：记录快照（用于恢复）
    self._snapshot_for_recovery(tc, result)
  
    return _ToolExecResult(
        tool_id=tc.tool_id,
        tool_name=tc.tool_name,
        result=result,
        elapsed=time.monotonic() - start,
        is_unknown=False,
    )
```

### 并发执行：多个工具同时跑

如果 AI 一次调用多个工具（比如同时读取 3 个文件），系统可以并发执行：

```python
async def _execute_batch_parallel(
    self, calls: list[ToolCallComplete]
) -> list[_ToolExecResult]:
    """并发执行多个工具调用"""
    tasks = [
        self._execute_single_tool_direct(tc) 
        for tc in calls
    ]
    return list(await asyncio.gather(*tasks))
```

**前提条件**：工具必须标记为 `is_concurrency_safe = True`

**为什么 ReadFile 可以并发？**

- 只读操作，不修改状态
- 每个文件路径独立

**为什么 WriteFile 不能并发？**

- 可能写入同一个文件
- 需要保证顺序一致性

## 第四步：工具分类 - 三种安全级别

```python
ToolCategory = Literal["read", "write", "command"]
```

### 为什么要分类？

**权限控制**：不同类别的工具需要不同的审批策略。

| 类别        | 示例                 | 风险 | 权限策略             |
| ----------- | -------------------- | ---- | -------------------- |
| `read`    | ReadFile, Glob, Grep | 低   | 自动允许             |
| `write`   | WriteFile, EditFile  | 中   | 需要用户确认         |
| `command` | Bash                 | 高   | 需要用户确认每条命令 |

```python
class Tool(ABC):
    category: ToolCategory = "read"
  
    @property
    def is_read_only(self) -> bool:
        return self.category == "read"
```

### 实际场景

**场景 1：AI 想读取文件**

```
AI: 调用 ReadFile("config.yaml")
系统: category = "read" → 自动执行 → 返回结果
```

**场景 2：AI 想写入文件**

```
AI: 调用 WriteFile("config.yaml", "new content")
系统: category = "write" → 弹出确认框
用户: [允许] / [拒绝]
```

**场景 3：AI 想执行命令**

```
AI: 调用 Bash("rm -rf /")
系统: category = "command" → 弹出确认框（高亮危险命令）
用户: [拒绝]
系统: 返回 "User denied execution"
```

## 第五步：延迟加载工具（Deferred Tools）

### 问题：工具太多怎么办？

假设系统有 100 个工具，如果全部发给 AI：

- Token 消耗巨大（每个工具的 schema 占几百 tokens）
- AI 难以选择（信息过载）
- 大部分工具根本用不到

### 解决方案：按需加载

```python
class Tool(ABC):
    should_defer: bool = False  # 是否延迟加载
```

**工作流程**：

```
初始请求
    ↓
只发送常用工具 (ReadFile, WriteFile, Bash, ...)
    ↓
系统提示AI可用的延迟工具列表 (system reminder)
    ↓
AI意识到需要team相关功能
    ↓
AI主动调用: ToolSearch(query="team", max_results=5)
    ↓
系统执行搜索: registry.search_deferred("team", 5)
    ↓
找到: TeamCreate(分数18), TeamDelete(分数15), ...
    ↓
标记为已发现: registry.mark_discovered("TeamCreate")
    ↓
返回工具schema给AI
    ↓
下次请求时包含这些工具 (get_all_schemas自动过滤)
    ↓
AI可以直接调用: TeamCreate(name="my-team")
```

**关键点**：系统**不会**自动从AI回复中抓取关键词，而是：

1. 通过system reminder告知AI有哪些延迟工具可用
2. AI根据需求**主动调用**ToolSearch
3. ToolSearch执行后标记工具为"已发现"
4. 下次请求自动包含已发现的工具

```python
# mewcode/tools/impl/tool_search.py
class ToolSearchTool(Tool):
    async def execute(self, params: ToolSearchParams) -> ToolResult:
        query = params.query
      
        # 支持两种模式
        if query.startswith("select:"):
            # 精确选择: select:TeamCreate,TeamDelete
            names = [n.strip() for n in query[7:].split(",")]
            schemas = self._registry.find_deferred_by_names(names, self._protocol)
        else:
            # 关键词搜索: "team"
            schemas = self._registry.search_deferred(
                query, params.max_results, self._protocol
            )
      
        # 标记为已发现
        for s in schemas:
            if "name" in s:
                self._registry.mark_discovered(s["name"])
      
        # 返回完整schema
        return ToolResult(
            output=f"Found {len(schemas)} tool(s). Their full schemas are now loaded:\n\n"
                   f"{json.dumps(schemas, indent=2, ensure_ascii=False)}"
        )
```

**步骤4：搜索算法**

```python
# mewcode/tools/__init__.py
def search_deferred(
    self, query: str, max_results: int, protocol: str = "anthropic"
) -> list[dict[str, Any]]:
    """搜索延迟加载的工具"""
    query_lower = query.lower()
    scored: list[tuple[int, str, Tool]] = []
  
    for name, tool in self._tools.items():
        if not tool.should_defer:
            continue  # 跳过非延迟工具
        if name in self._disabled:
            continue  # 跳过禁用的工具
    
        # 计算相关性分数
        score = 0
        name_lower = name.lower()
        desc_lower = (tool.description or "").lower()
    
        if query_lower in name_lower:
            score += 10  # 名称完全匹配
        if query_lower in desc_lower:
            score += 5   # 描述匹配
    
        for word in query_lower.split():
            if word in name_lower:
                score += 3  # 名称部分匹配
            if word in desc_lower:
                score += 1  # 描述部分匹配
    
        if score > 0:
            scored.append((score, name, tool))
  
    # 按分数排序，返回前 N 个
    scored.sort(key=lambda x: x[0], reverse=True)
  
    # 格式化为schema
    results: list[dict[str, Any]] = []
    for _, _name, tool in scored[:max_results]:
        base = tool.get_schema()
        if protocol in ("openai", "openai-compat"):
            results.append({
                "type": "function",
                "name": base["name"],
                "description": base["description"],
                "parameters": base["input_schema"],
            })
        else:
            results.append(base)
  
    return results
```

### 状态管理

```python
# mewcode/tools/__init__.py
class ToolRegistry:
    def __init__(self):
        self._tools: dict[str, Tool] = {}           # 所有已注册工具
        self._disabled: set[str] = set()            # 被禁用的工具
        self._discovered: set[str] = set()          # 已被发现的延迟工具
  
    def mark_discovered(self, name: str) -> None:
        """标记延迟工具为已发现"""
        self._discovered.add(name)
  
    def get_deferred_tool_names(self) -> list[str]:
        """返回所有未发现的延迟工具名称"""
        return [
            name
            for name, tool in self._tools.items()
            if getattr(tool, "should_defer", False)
            and name not in self._discovered
            and name not in self._disabled
        ]
  
    def get_all_schemas(self, protocol: str = "anthropic") -> list[dict[str, Any]]:
        """导出所有可用工具的schema"""
        schemas: list[dict[str, Any]] = []
      
        for name, tool in self._tools.items():
            if name in self._disabled:
                continue
          
            # 关键过滤：跳过未被发现的延迟工具
            if getattr(tool, "should_defer", False) and name not in self._discovered:
                continue
          
            base = tool.get_schema()
            # ... 协议格式化
            schemas.append(base)
      
        return schemas
```

### ToolResult：统一的返回格式

```python
@dataclass
class ToolResult:
    output: str              # 输出内容
    is_error: bool = False   # 是否是错误
```

**为什么这么简单？**

AI 只需要两种信息：

1. **结果内容**（成功时的输出，失败时的错误信息）
2. **是否成功**（决定后续行为）

## 第七步：工具的 Schema 生成

### AI 需要知道什么

当你告诉 AI "你可以使用 ReadFile 工具"，AI 需要知道：

1. 工具名称是什么
2. 工具做什么
3. 需要哪些参数
4. 每个参数是什么类型

这些信息通过 JSON Schema 传递：

```python
def get_schema(self) -> dict[str, Any]:
    schema = self.params_model.model_json_schema()
    schema.pop("title", None)  # 移除不需要的字段
    return {
        "name": self.name,
        "description": self.description,
        "input_schema": schema,
    }
```

### 协议适配：Anthropic vs OpenAI

不同的 AI 服务商要求不同的格式：

```python
def get_all_schemas(self, protocol: str = "anthropic") -> list[dict]:
    schemas = []
    for name, tool in self._tools.items():
        base = tool.get_schema()
    
        if protocol in ("openai", "openai-compat"):
            # OpenAI 格式：嵌套在 function 键下
            schemas.append({
                "type": "function",
                "function": {
                    "name": base["name"],
                    "description": base["description"],
                    "parameters": base["input_schema"],
                }
            })
        else:
            # Anthropic 格式：直接返回
            schemas.append(base)
  
    return schemas
```

## 代码亮点：设计模式与最佳实践

### 亮点 1：抽象基类 + 模板方法

```python
class Tool(ABC):
    @abstractmethod
    async def execute(self, params: BaseModel) -> ToolResult:
        """子类必须实现"""
        ...
  
    def get_schema(self) -> dict[str, Any]:
        """模板方法，所有工具共用"""
        schema = self.params_model.model_json_schema()
        return {
            "name": self.name,
            "description": self.description,
            "input_schema": schema,
        }
```

**好处**：

- 新增工具只需实现 `execute()`
- Schema 生成逻辑统一，不会出错
- 类型检查保证接口一致

class ReadFile(Tool):

### 亮点 4：注册表模式

```python
class ToolRegistry:
    def __init__(self):
        self._tools: dict[str, Tool] = {}
  
    def register(self, tool: Tool):
        self._tools[tool.name] = tool
  
    def get(self, name: str) -> Tool | None:
        return self._tools.get(name)
```

**好处**：

- **解耦**：工具实现与工具查找分离
- **动态**：运行时可以注册/注销工具
- **可测试**：可以创建不同的注册表实例

**对比硬编码**：

```python
# ❌ 硬编码
def execute_tool(name: str, args: dict):
    if name == "ReadFile":
        return ReadFile().execute(args)
    elif name == "WriteFile":
        return WriteFile().execute(args)
    elif name == "Bash":
        return Bash().execute(args)
    # ... 100 个 elif
```

### 亮点 5：错误处理的层次

```
第 1 层：工具不存在
    → 返回 ToolResult(is_error=True)
    → AI 看到错误，修正工具名

第 2 层：参数验证失败
    → Pydantic 抛出 ValidationError
    → 捕获并转换为 ToolResult(is_error=True)
    → AI 看到错误，修正参数

第 3 层：执行失败
    → 工具内部返回 ToolResult(is_error=True)
    → AI 看到错误，尝试其他方法

第 4 层：未捕获异常
    → try-except 捕获
    → 转换为 ToolResult(is_error=True)
    → 系统不会崩溃
```

每一层都有降级策略，确保系统稳定。

### 场景 1：新增自定义工具

```python
# 定义参数
class GitStatusParams(BaseModel):
    repo_path: str = Field(default=".", description="仓库路径")

# 实现工具
class GitStatus(Tool):
    name = "GitStatus"
    description = "查看 Git 仓库状态"
    params_model = GitStatusParams
    category = "read"
    is_concurrency_safe = True
  
    async def execute(self, params: GitStatusParams) -> ToolResult:
        import subprocess
        try:
            result = subprocess.run(
                ["git", "status", "--short"],
                cwd=params.repo_path,
                capture_output=True,
                text=True,
                timeout=5
            )
            return ToolResult(output=result.stdout)
        except Exception as e:
            return ToolResult(output=f"Error: {e}", is_error=True)

# 注册
registry.register(GitStatus())
```
