```
AI看到提示 → 决定需要team工具 → 调用ToolSearch(query="team")
```

## 关键澄清

### 延迟加载工具的实现真相

**很多文档可能让人误解系统会自动抓取关键词，但实际上**：

1. ✅ 系统通过`system reminder`告知AI可用的延迟工具列表
2. ✅ System prompt中提示AI使用ToolSearch
3. ✅ AI根据需求**主动决定**调用ToolSearch
4. ✅ ToolSearch执行后标记工具为"已发现"
5. ✅ 下次请求`get_all_schemas()`自动包含已发现的工具

**没有任何自动关键词抓取逻辑**，这是一个完全由AI驱动的过程。
