# CH09: 命令注册与分发

## 从一个真实场景说起

你在使用 AI Agent 时，突然想要：

```
查看所有可用的会话 → 输入 /session list
清空当前对话历史 → 输入 /clear
压缩对话以节省 token → 输入 /compact
调用某个技能 → 输入 /skill review
```

**问题来了：**

1. **如何识别这些命令？** `/session` 和 `/clear` 是完全不同的命令
2. **如何找到对应的处理器？** 每个命令有不同的逻辑
3. **如何处理别名？** `/s` 应该等同于 `/session`
4. **如何自动补全？** 输入 `/se` 应该提示 `/session`
5. **如何传递参数？** `/session list` 中的 `list` 是参数

这就是为什么需要**命令注册与分发系统**：

- **命令解析器**：识别用户输入的命令
- **命令注册表**：管理所有可用命令
- **命令分发器**：路由到正确的处理器
- **自动补全**：智能提示可用命令

---

## 核心挑战：如何设计一个可扩展的命令系统？

### 挑战 1：不同类型的命令

```
类型 1：本地命令（不经过 LLM）
    /clear → 直接清空对话
    /help → 直接显示帮助
    /session list → 直接列出会话

类型 2：UI 命令（需要 UI 交互）
    /session → 显示会话选择界面
    /permission → 显示权限配置界面

类型 3：Prompt 命令（通过 LLM 处理）
    /skill review → 加载技能 prompt，发给 LLM
    /compact → 触发对话压缩（需要调用 LLM）
```

### 挑战 2：命令冲突和别名

```
问题 1：命名冲突
    命令 A: /session
    命令 B: /session  ← 冲突！

问题 2：别名冲突
    命令 A: /session (别名: /s)
    命令 B: /status (别名: /s)  ← 别名冲突！

问题 3：命令与别名冲突
    命令 A: /session
    命令 B: /task (别名: /session)  ← 冲突！
```

### 挑战 3：命令补全

```
用户输入: /se
    → 应该提示: /session, /set
    → 不应该提示: /clear, /help

用户输入: /s
    → 应该提示: /session, /status, /skill
    → 按字母顺序排列
    → 最多显示 8 条（避免界面太长）
```

---

## 系统的解决方案：三层架构

```
Layer 1: 命令解析（Parser）
    ├─ 识别斜杠命令 (/xxx)
    ├─ 提取命令名和参数
    └─ 自动补全匹配

Layer 2: 命令注册（Registry）
    ├─ 注册命令和别名
    ├─ 检测命名冲突
    ├─ 查找命令
    └─ 列出所有命令

Layer 3: 命令处理（Handlers）
    ├─ 本地命令处理器 (local)
    ├─ UI 命令处理器 (local_ui)
    └─ Prompt 命令处理器 (prompt)
```

## Layer 1: 命令解析 - 从文本到命令

### 命令格式

```
格式: /command [arguments]

示例:
/help              → 命令: help, 参数: ""
/session list      → 命令: session, 参数: "list"
/skill review      → 命令: skill, 参数: "review"
/memory clear      → 命令: memory, 参数: "clear"
```

### 解析逻辑

```python
# commands/parser.py:7-17
def parse_command(text: str) -> tuple[str, str, bool]:
    """
    解析用户输入的命令
    返回: (命令名, 参数, 是否为有效命令)
    """
    text = text.strip()
    
    # 1. 不是斜杠开头，不是命令
    if not text.startswith("/"):
        return "", "", False
    
    # 2. 去除斜杠
    text = text[1:]
    if not text:
        return "", "", True  # 只有斜杠，算有效但空命令
    
    # 3. 分割命令名和参数（第一个空格处分割）
    parts = text.split(None, 1)
    name = parts[0].lower()  # 命令名转小写
    args = parts[1].strip() if len(parts) > 1 else ""
    
    return name, args, True
```

**实际效果**：

```python
parse_command("help me")
→ ("", "", False)  # 不是命令

parse_command("/")
→ ("", "", True)  # 空命令

parse_command("/help")
→ ("help", "", True)

parse_command("/session list")
→ ("session", "list", True)

parse_command("/HELP")
→ ("help", "", True)  # 自动转小写

parse_command("/skill review --detailed")
→ ("skill", "review --detailed", True)
```

**设计要点**：

- **大小写不敏感**：`/HELP` 和 `/help` 等价
- **参数保留原样**：`review --detailed` 不转小写
- **split(None, 1)**：按第一个空格分割，最多分成 2 部分

### 命令补全

**需求：用户输入前缀时，智能提示可用命令**

```python
# commands/parser.py:21-38
def complete(registry: CommandRegistry, prefix: str) -> list[tuple[str, str]]:
    """
    返回匹配命令的 (display_text, command_value) 列表
    
    display_text: 显示给用户的文本
    command_value: 实际填充的命令
    """
    prefix = prefix.lstrip("/")  # 去除斜杠
    seen: set[str] = set()
    matches: list[tuple[str, str]] = []
    
    # 1. 遍历所有命令
    for cmd in registry.list_commands():
        if cmd.name in seen:
            continue
        
        # 2. 匹配命令名或别名
        if cmd.name.startswith(prefix) or any(a.startswith(prefix) for a in cmd.aliases):
            seen.add(cmd.name)
            
            # 3. 格式化显示文本
            desc = cmd.description
            if len(desc) > 30:
                desc = desc[:28] + "…"
            desc = desc.replace("[", "\\[")  # 转义特殊字符
            display = f"/{cmd.name:<16} — {desc}"
            
            matches.append((display, "/" + cmd.name))
    
    # 4. 排序并限制数量
    matches.sort(key=lambda x: x[1])
    return matches[:8]  # 最多 8 条
```

**实际效果**：

```python
# 用户输入: /se
complete(registry, "/se")
→ [
    ("/session         — Manage sessions", "/session"),
    ("/set             — Configure settings", "/set"),
]

# 用户输入: /s
complete(registry, "/s")
→ [
    ("/session         — Manage sessions", "/session"),
    ("/skill           — Execute a skill", "/skill"),
    ("/status          — Show agent status", "/status"),
]

# 用户输入: /help
complete(registry, "/help")
→ [
    ("/help            — Show help message", "/help"),
]
```

**设计要点**：

- **匹配别名**：如果命令有别名 `/s`，输入 `/s` 也能匹配
- **去重**：同一个命令只显示一次（即使有多个别名匹配）
- **描述截断**：超过 30 字符的描述会被截断
- **固定宽度**：命令名部分固定 16 字符宽度（对齐）
- **限制数量**：最多 8 条，避免界面太长

### 注册命令

```python
# commands/registry.py:52-88
class CommandRegistry:
    def __init__(self) -> None:
        self._commands: dict[str, Command] = {}      # 命令名 → Command
        self._alias_map: dict[str, str] = {}         # 别名 → 命令名
        self._lock = asyncio.Lock()                  # 并发保护
    
    async def register(self, command: Command) -> None:
        async with self._lock:
            # 1. 检查命令名冲突
            if command.name in self._commands or command.name in self._alias_map:
                raise ValueError(
                    f"Command name '{command.name}' conflicts with an existing command or alias"
                )
            
            # 2. 检查别名冲突
            for alias in command.aliases:
                if alias in self._alias_map or alias in self._commands:
                    raise ValueError(
                        f"Alias '{alias}' conflicts with an existing command or alias"
                    )
            
            # 3. 注册命令
            self._commands[command.name] = command
            
            # 4. 注册别名
            for alias in command.aliases:
                self._alias_map[alias] = command.name
    
    def register_sync(self, command: Command) -> None:
        """同步版本（用于初始化时）"""
        # 同样的检查逻辑
        if command.name in self._commands or command.name in self._alias_map:
            raise ValueError(...)
        for alias in command.aliases:
            if alias in self._alias_map or alias in self._commands:
                raise ValueError(...)
        
        self._commands[command.name] = command
        for alias in command.aliases:
            self._alias_map[alias] = command.name
```

**为什么需要两个版本？**

- **register()**：异步版本，支持并发注册
- **register_sync()**：同步版本，用于启动时批量注册

**冲突检测规则**：

```
规则 1：命令名不能和已有命令名冲突
    已有: /session
    注册: /session → ❌ 冲突

规则 2：命令名不能和已有别名冲突
    已有: /session (别名: /s)
    注册: /s → ❌ 冲突

规则 3：别名不能和已有命令名冲突
    已有: /session
    注册: /task (别名: /session) → ❌ 冲突

规则 4：别名不能和已有别名冲突
    已有: /session (别名: /s)
    注册: /status (别名: /s) → ❌ 冲突
```

### 查找命令

```python
# commands/registry.py:90-96
def find(self, name: str) -> Command | None:
    """根据命令名或别名查找命令"""
    # 1. 直接查找命令名
    if name in self._commands:
        return self._commands[name]
    
    # 2. 查找别名对应的命令名
    canon = self._alias_map.get(name)
    if canon:
        return self._commands.get(canon)
    
    # 3. 未找到
    return None
```

## Layer 3: 命令处理器 - 执行命令逻辑

### 命令类型详解

**类型 1: LOCAL 命令**

```python
# 示例：/clear 命令

async def handle_clear(ctx: CommandContext) -> None:
    """清空当前对话历史"""
    # 直接操作对话管理器
    ctx.conversation.history.clear()
    
    # 显示系统消息
    ctx.ui.add_system_message("对话历史已清空")
```

**特点**：

- **不经过 LLM**：直接执行逻辑
- **快速响应**：无需等待 API 调用
- **确定性**：行为完全可预测

**类型 2: LOCAL_UI 命令**

```python
# 示例：/session 命令
# commands/handlers/session.py

async def handle_session(ctx: CommandContext) -> None:
    """显示会话管理界面"""
    if not ctx.args:
        # 没有参数，显示 UI 界面
        # UI 会弹出会话选择对话框
        return
    
    # 有参数，执行对应操作
    if ctx.args == "list":
        sessions = ctx.session_manager.list()
        for s in sessions:
            ctx.ui.add_system_message(f"- {s.title}")
    elif ctx.args.startswith("resume"):
        session_id = ctx.args.split()[1]
        result = ctx.session_manager.resume(session_id)
        ...
```

**特点**：

- **需要 UI 交互**：弹出对话框或选择界面
- **两种模式**：有参数时执行逻辑，无参数时显示 UI
- **用户友好**：通过界面操作，不需要记忆参数

**类型 3: PROMPT 命令**

```python
# 示例：/compact 命令
# commands/handlers/compact.py

async def handle_compact(ctx: CommandContext) -> None:
    """手动触发对话压缩"""
    # 1. 检查是否需要压缩
    current_tokens = ctx.conversation.current_tokens()
    if current_tokens < threshold:
        ctx.ui.add_system_message(f"当前 {current_tokens} tokens，无需压缩")
        return
    
    # 2. 调用压缩逻辑（会调用 LLM 生成摘要）
    from mewcode.context.manager import auto_compact
    
    result = await auto_compact(
        ctx.conversation,
        ctx.agent.client,
        ctx.agent.context_window,
        session_dir,
        manual=True,
    )
    
    if isinstance(result, CompactEvent):
        saved = result.before_tokens - ctx.conversation.current_tokens()
        ctx.ui.add_system_message(f"压缩完成，节省 {saved} tokens")
```

**特点**：

- **可能调用 LLM**：执行逻辑中需要 API 调用
- **异步执行**：需要等待 LLM 响应
- **复杂逻辑**：涉及多个子系统协作

## 技能系统（Skill）- 特殊的命令

### 什么是技能？

```
技能 = 预定义的 Prompt + 可选的工具限制

示例：代码审查技能
    名称: review
    Prompt: "请审查以下代码，关注..."
    允许的工具: ["Read", "Grep", "Bash"]
    模式: fork (独立运行)
```

### 技能定义格式

```markdown
---
name: review
description: 代码审查技能
mode: fork
context: recent
allowedTools:
  - Read
  - Grep
  - Bash
---

请审查用户提供的代码，重点关注：

1. **代码质量**：可读性、命名规范、注释
2. **潜在 Bug**：边界条件、空值处理、异常处理
3. **性能问题**：算法复杂度、不必要的循环

```

```python
# skills/loader.py:24-41
def load_all(self) -> dict[str, SkillDef]:
    seen: dict[str, SkillDef] = {}
    
    # 1. 加载项目技能（优先级最高）
    for skill in self._scan_directory(self._project_dir, "project"):
        if skill.name not in seen:
            seen[skill.name] = skill
    
    # 2. 加载用户技能
    for skill in self._scan_directory(self._user_dir, "user"):
        if skill.name not in seen:  # 不覆盖项目技能
            seen[skill.name] = skill
    
    # 3. 加载内置技能
    for skill in self._load_builtins():
        if skill.name not in seen:  # 不覆盖用户技能
            seen[skill.name] = skill
    
    self._skills = seen
    self._cache = {k: v for k, v in seen.items()}
    return seen
```

**目录扫描**：

```python
# skills/loader.py:44-65
def _scan_directory(self, path: Path, source: str) -> list[SkillDef]:
    results: list[SkillDef] = []
    if not path.is_dir():
        return results
    
    for entry in sorted(path.iterdir()):
        try:
            # 情况 1：单文件技能 (skill.md)
            if entry.is_file() and entry.suffix == ".md":
                skill = parse_skill_file(entry)
                skill.source_path = entry
                results.append(skill)
            
            # 情况 2：目录技能 (skill/SKILL.md)
            elif entry.is_dir():
                skill_md = entry / "SKILL.md"
                if skill_md.is_file():
                    skill = parse_skill_file(skill_md)
                    skill.source_path = skill_md
                    skill.is_directory = True
                    results.append(skill)
        
        except SkillParseError as e:
            log.warning("Skipping %s skill '%s': %s", source, entry.name, e)
    
    return results
```

### 技能热重载

```python
# skills/loader.py:103-122
def get(self, name: str) -> SkillDef | None:
    """获取技能（支持热重载）"""
    skill = self._skills.get(name)
    if skill is None:
        return None
    
    # 如果有源文件路径，尝试重新加载
    if skill.source_path is not None:
        try:
            fresh = parse_skill_file(skill.source_path)
            fresh.is_directory = skill.is_directory
            
            # 更新缓存
            self._skills[name] = fresh
            self._cache[name] = fresh
            return fresh
        
        except SkillParseError as e:
            log.warning(
                "Hot-reload failed for skill '%s', using cached version: %s",
                name, e,
            )
```

```python
async def execute_fork(self, skill: SkillDef, args: str) -> str:
    """在独立的 Agent 中运行技能"""
    prompt = substitute_arguments(skill.prompt_body, args)
    
    # 1. 记录到恢复状态
    if getattr(self.agent, "recovery_state", None) is not None:
        self.agent.recovery_state.record_skill_invocation(
            skill.name, skill.prompt_body
        )
    
    # 2. 创建独立的对话管理器
    fork_conv = ConversationManager()
    
    # 3. 构建上下文（根据 context 模式）
    context_messages = self._build_fork_context(skill.context)
    for msg in context_messages:
        if msg.role == "user":
            fork_conv.add_user_message(msg.content)
        else:
            fork_conv.add_assistant_message(msg.content)
    
    # 4. 添加技能 prompt
    fork_conv.add_user_message(prompt)
    
    # 5. 过滤工具注册表（只允许指定的工具）
    try:
        filtered_registry = filter_tool_registry(
            self.agent.registry, skill.allowed_tools
        )
    except SkillDependencyError as e:
        return f"Skill execution failed: {e}"
    
    # 6. 创建独立的 Agent
    fork_agent = AgentClass(
        client=self.client,
        registry=filtered_registry,  # 限制工具访问
        protocol=self.protocol,
        work_dir=self.agent.work_dir,
        max_iterations=self.agent.max_iterations,
        permission_checker=None,  # fork 不需要权限检查
        context_window=self.agent.context_window,
    )
    
    # 7. 运行 Agent，收集输出
    result_parts: list[str] = []
    async for event in fork_agent.run(fork_conv):
        if isinstance(event, StreamText):
            result_parts.append(event.text)
        elif isinstance(event, ErrorEvent):
            result_parts.append(f"\n[Error: {event.message}]")
        elif isinstance(event, LoopComplete):
            break
    
    return "".join(result_parts)
```

```python
# skills/executor.py:25-44
def filter_tool_registry(
    registry: ToolRegistry, allowed: list[str]
) -> ToolRegistry:
    """过滤工具注册表，只保留允许的工具"""
    if not allowed:
        return registry  # 没有限制，返回完整注册表
    
    filtered = ToolRegistry()
    
    # 1. 注册允许的工具
    for name in allowed:
        tool = registry.get(name)
        if tool is None:
            raise SkillDependencyError(
                f"Skill requires tool '{name}' but it is not registered"
            )
        filtered.register(tool)
    
    # 2. 自动添加系统工具（如 LoadSkill）
    for tool in registry.list_tools():
        if getattr(tool, "is_system_tool", False) and filtered.get(tool.name) is None:
            filtered.register(tool)
    
    return filtered
```

```
禁止的工具:
    ✗ Write - 不应该修改代码
    ✗ Delete - 不应该删除文件
    ✗ Bash (危险命令) - 不应该执行 rm -rf

好处:
    1. 安全性：限制技能的权限
```

```python
# ✅ 好做法：注册时检测所有冲突
async def register(self, command: Command) -> None:
    # 检查命令名冲突
    if command.name in self._commands or command.name in self._alias_map:
        raise ValueError(f"Command name '{command.name}' conflicts...")
    
    # 检查别名冲突
    for alias in command.aliases:
        if alias in self._alias_map or alias in self._commands:
            raise ValueError(f"Alias '{alias}' conflicts...")

# ❌ 坏做法：直接覆盖
def register(self, command: Command) -> None:
```

```python
def find(self, name: str) -> Command | None:

    if name in self._commands:
        return self._commands[name]
    
    # 第 2 步：查找别名对应的命令名

    return None
```
